Setup Akun

Akun Administrator

Buat akun Auth terlebih dahulu di Supabase Dashboard, lalu tetapkan peran administrator di sini.

1. Buat akun Auth Di Supabase Dashboard buka Authentication → Users → Add user. Gunakan email dan password milik administrator.
2. Pastikan profil tersedia Setelah akun dibuat, sistem otomatis membuat profil dengan peran awal guru.
3. Aktifkan peran admin Gunakan tombol Jadikan Admin pada daftar akun di bawah.
